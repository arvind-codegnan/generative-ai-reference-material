# Generative AI for Java Freshers

> A two-part learning path covering Generative AI integration first with Core Java and then with Spring Boot and Spring AI.

## Learning Path

```text
Part 1: Generative AI Fundamentals with Core Java
                         |
                         v
Part 2: Generative AI with Spring Boot and Spring AI
```

| Part | Notes | Main coverage |
| --- | --- | --- |
| 1 | [Generative AI Notes for Java Freshers](generative-ai-notes-for-java-freshers.md) | AI foundations, prompts, tokens, structured output, embeddings, vector databases, RAG, tools, Java `HttpClient`, streaming, memory, evaluation, security, and cost |
| 2 | [Generative AI with Spring Notes for Java Freshers](generative-ai-with-spring-notes-for-java-freshers.md) | Spring Boot, Spring AI, `ChatClient`, advisors, JDBC chat memory, tool calling, vector stores, document ETL, RAG, PGvector, observability, testing, and MCP |

## Recommended Study Order

1. Complete [Part 1: Generative AI with Core Java](generative-ai-notes-for-java-freshers.md).
2. Revise prompts, structured output, embeddings, RAG, tools, and conversation memory.
3. Continue to [Part 2: Generative AI with Spring](generative-ai-with-spring-notes-for-java-freshers.md).
4. Build the Java Learning Assistant mini-project described in Part 2.
